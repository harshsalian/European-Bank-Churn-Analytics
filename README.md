# Customer Segmentation & Churn Pattern Analytics in European Banking

### 🏦 Project Overview
This project addresses retail banking customer churn for the European Central Bank. By employing advanced data cleaning and custom feature engineering in Python, and building an interactive Tableau Dashboard, we isolated high-risk customer segments to prevent institutional wealth leakage.

### 🛠️ Tech Stack Used
* **Data Processing:** Python (Pandas, NumPy)
* **Data Visualization & Analytics:** Tableau Public / Desktop
* **Development Environment:** Google Colab

### 📊 Key Insights Found
* **Geographic Risk Index:** Germany exhibits a critical churn rate of **32.44%**, which is double the baseline of France (16.15%) and Spain (16.67%).
* **Senior Crisis Demographic:** Customers aged **46–60** represent the highest volatility with a staggering **51.12%** churn rate.
* **Premium Wealth Leak:** High-balance premium accounts are leaving at a rate of **25.23%**, significantly out-pacing zero-balance segments.

### 🚀 Strategic Recommendations
1. Conduct a localized product and fee audit for German bank branches.
2. Design tailored wealth-retention incentives for the mature 46-60 age bracket.
3. Set proactive automated alerts for inactive users before complete asset exit.
